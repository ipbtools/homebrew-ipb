# hdbtools/homebrew-hdb

Homebrew tap for [hdb](https://github.com/hdbtools/hdb), the HID / Hub Debug Bridge for iOS devices.

```sh
brew tap hdbtools/hdb
brew install --HEAD hdb
hdb version
```

Requirements: macOS 27 (or macOS 26.4+) with Xcode 27 beta installed and selected for the build; an iOS 27 or iOS 26.6+ device paired over USB. See the hdb README for details.
